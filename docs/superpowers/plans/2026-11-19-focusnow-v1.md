# FocusNow v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native macOS menu bar pomodoro timer with focus/break cycles, a session log, stats by day/week/month/year/all time, and a daily goal.

**Architecture:** One Swift package with two targets. `FocusNowCore` is a library holding all logic (timer state machine, settings, storage, stats) with an injected clock, tested with `swift test`. `FocusNow` is an AppKit-lifecycle executable that hosts SwiftUI views in an `NSStatusItem` popover and two `NSWindow`s. A shell script assembles and ad-hoc signs `build/FocusNow.app`; there is no Xcode project.

**Tech Stack:** Swift 6 (language mode 6), SwiftUI, AppKit, SwiftData, Swift Charts, UserNotifications, ServiceManagement, Swift Testing.

**Spec:** `docs/superpowers/specs/2026-11-19-focusnow-v1-design.md`. Read it before starting any task. Mockups: `.superpowers/brainstorm/69458-1795079963/content/popover-layout.html` (card A) and `stats-window.html`.

## Global Constraints

- Apple frameworks only. No third-party packages.
- Minimum macOS 14 (`platforms: [.macOS(.v14)]`).
- Every time value on screen uses tabular (monospaced) digits.
- Defaults: 40 min focus, 5 min short break, 15 min long break, long break after every 4th focus session, 4 h daily goal, sound on, launch at login off.
- Stats count `activeSeconds` of focus sessions only. Breaks are stored and never shown in totals.
- Blank time (asleep, paused, waiting) never counts toward focus or rest.
- Nothing auto-advances: after a countdown ends the app waits for a click.
- Colours live in one file (`Theme.swift`) and the icon is one swappable asset; the owner may change both later.
- Motion follows the spec's "Look and motion" list. Countdown digits never animate.
- All `FocusNowCore` types that touch state are `@MainActor`. Time comes only from the injected `clock: () -> Date` and `calendar`, never `Date()` or `Calendar.current` inside logic.
- Initialise git in Task 1 and commit at the end of every task.

## Review Focus

1. **A long gap between ticks with no sleep notification** (forced sleep, a stalled process): the gap is blank time, not focus. Test in Task 4.
2. **A corrupt or unreadable snapshot file:** the app starts idle with no crash and no phantom session. Test in Task 4.
3. **Settings changed while a session runs:** the running session keeps the length it started with; the new length applies to the next one. Test in Task 2.
4. **An action that is invalid in the current state** (Start while running, Resume while idle, a double End early): it does nothing and never writes a second record. Test in Task 2.
5. **Daylight-saving days** (23 or 25 hours): a week still has 7 day buckets and a session lands on its local start day. Test in Task 6.

Test helper: `func makeEngine(at iso: String = "2026-11-19T09:00:00Z") -> (engine: TimerEngine, clock: FakeClock, sessions: InMemorySessionStore, snapshots: InMemorySnapshotStore, settings: SettingsBox)` where `SettingsBox` is a class holding a mutable `TimerSettings`. Tests advance time with `run(_ seconds:)`, a helper that advances the clock in 1-second steps calling `engine.tick()` after each, so the tick-gap rule from Task 4 never triggers by accident.

Behaviour this task pins:

- `start()` from idle begins `nextKind` with `plannedSecondsForNext`, and clears `needsAttention` and the override.
- `tick()` sets `now`; when a running session's active time reaches its planned length it saves a `.completed` record with `activeSeconds == plannedSeconds` and `endedAt` equal to the exact moment the countdown reached zero (not the tick time), then goes idle, sets `needsAttention = true` and calls `onFinish(kind)`.
- `endEarly()` (running or paused) saves an `.endedEarly` record with the active time so far and `endedAt = now`. A focus session under 60 active seconds is discarded as if cancelled.
- `cancel()` saves nothing and returns to idle with `nextKind` unchanged.
- Every action that does not apply to the current status is a no-op.

### Task 3: Timer engine — focus/break cycle

**Files:**
- Modify: `Sources/FocusNowCore/TimerEngine.swift`
- Test: `Tests/FocusNowCoreTests/TimerEngineCycleTests.swift`

**Interfaces — Consumes:** Task 2. **Produces:** no new names. Behaviour:

- After a focus session is logged (completed, or ended early with ≥ 60 s), `cyclePosition += 1`. If `cyclePosition >= sessionsBeforeLongBreak`, `nextKind = .longBreak`, else `.shortBreak`.
- After any break finishes, is ended by `skipBreak()` while running or paused, or is skipped before starting, `nextKind = .focus`. After a long break (finished or skipped) `cyclePosition = 0`.
- `skipBreak()` on a running or paused break saves it as `.endedEarly` with its active time. Skipped before starting, nothing is saved. It clears `needsAttention`. It is a no-op when `nextKind`/active kind is focus.
- A break that completes sets `needsAttention` and calls `onFinish`, like focus.
- Break lengths come from settings; `nextFocusSecondsOverride` never applies to breaks.
- `acknowledge()` sets `needsAttention = false` and changes nothing else.
- On `start()`, if the clock's day differs from the day the cycle began, `cyclePosition = 0` first, and a pending break becomes focus.

### Task 4: Timer engine — blank time, snapshots, quit and crash recovery

**Files:**
- Create: `Sources/FocusNowCore/FileSnapshotStore.swift`
- Modify: `Sources/FocusNowCore/TimerEngine.swift`
- Test: `Tests/FocusNowCoreTests/TimerEngineBlankTests.swift`

**Interfaces — Produces:**

```swift
extension TimerEngine { public static let blankGapSeconds: TimeInterval = 30
                        public static let snapshotIntervalSeconds: TimeInterval = 15 }
public final class FileSnapshotStore: SnapshotStore { public init(url: URL) }
```

Behaviour:

- **Tick gap:** the engine remembers the time of its last tick or action. If `tick()` arrives more than 30 s after it while a session is running, the session is paused as of that last time: the gap is blank. Remaining time is unchanged by the gap.
- **`systemWillSleep()`:** pauses a running session at the current time. No-op otherwise.
- **Snapshots:** the engine saves an `EngineSnapshot` after every state change and whenever a tick finds 15 s have passed since the last save. `savedAt` is the clock time of the save.
- **`prepareForQuit()`:** a running or paused session is ended as `endEarly()` would (60 s rule included), then a snapshot with `active == nil` is saved.
- **Recovery in `init`:** load the snapshot. If it has an active session, log it as `.endedEarly` with `endedAt = savedAt` and active time computed at `savedAt` (60 s rule and cycle rules apply), with no `onFinish` and no `needsAttention`. Restore `cyclePosition` and `nextKind`, unless `cycleDay` is not today, in which case start a fresh cycle. A `nil` snapshot means a fresh idle engine.
- **`FileSnapshotStore`:** JSON at `url`, written atomically, creating the parent directory. `load()` returns `nil` for a missing, empty or undecodable file.

### Task 6: Stats calculator

**Files:**
- Create: `Sources/FocusNowCore/StatsCalculator.swift`
- Test: `Tests/FocusNowCoreTests/StatsCalculatorTests.swift`

**Interfaces — Produces:**

```swift
public enum StatsRange: String, CaseIterable, Sendable { case day, week, month, year, allTime }
public struct StatsBucket: Equatable, Identifiable, Sendable {
    public var interval: DateInterval; public var focusSeconds: Int
    public var goalSeconds: Int?            // set only for day-sized buckets
    public var id: Date { interval.start }
}
public struct StatsSummary: Equatable, Sendable { public var dailyAverageSeconds: Int; public var goalMetDays: Int; public var elapsedDays: Int }

public struct StatsCalculator: Sendable {
    public init(calendar: Calendar)
    public func focusSeconds(_ sessions: [SessionRecord]) -> Int      // focus kind only
    public func focusCount(_ sessions: [SessionRecord]) -> Int
    public func interval(for range: StatsRange, containing date: Date, earliest: Date?) -> DateInterval
    public func buckets(for range: StatsRange, interval: DateInterval,
                        sessions: [SessionRecord], goal: (Date) -> Int) -> [StatsBucket]
    public func summary(interval: DateInterval, sessions: [SessionRecord],
                        today: Date, goal: (Date) -> Int) -> StatsSummary
}
```

Rules:

- A session is attributed to the bucket containing its `startedAt`, whole.
- Bucket sizes: day → 24 hours; week → 7 days; month → each day of the month; year → 12 months; all time → months, or years when the interval spans more than 24 months.
- The all-time interval runs from the start of the month of `earliest` (or of `date` if `nil`) to the end of the month containing `date`; widened to whole years when yearly.
- `summary` counts only days in the interval up to and including `today`. `dailyAverageSeconds` = focus seconds ÷ `elapsedDays`. `goalMetDays` = days whose focus seconds ≥ `goal(day)`.
