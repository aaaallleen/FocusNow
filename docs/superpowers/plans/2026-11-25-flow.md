# Flow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `Focus | Flow` switch at the top of the timer. A flow counts up from 00:00 until Stop, or until the 10-minute idle stop. It's saved as focus and listed as "flow", and it stays outside the Pomodoro cycle.

**Architecture:**
- **A flow is a focus "past zero" from its first second.** It's an `ActiveSession` with `kind == .focus`, `plannedSeconds == 0` and `timeUpAt == startedAt`. So `feat/run-over`'s counting up, idle stop, sleep trimming, quit and crash recovery apply to it.
- **The engine gains** the remembered switch choice, `stop()`, and flow cases in `finish`, `tick`, `controls` and `clockLabel`.
- **The app replaces `PhaseLabel`** with a header (the switch, plus the cycle line), draws hourly ring laps, and labels flow rows in Stats.

**Tech Stack:** Swift 6, SwiftPM (FocusNowCore + FocusNow), SwiftUI + AppKit, Swift Testing, macOS 14+.

**Spec:** `docs/superpowers/specs/2026-11-25-flow-design.md`

## Global Constraints

- **Branch:** `feat/flow`, built on `feat/run-over` (PR #7, unmerged). Commit there and don't push. Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Copy, verbatim:**
  - Switch segments: `Focus` and `Flow`.
  - Buttons: `Start flow` and `Stop`.
  - Stats row: `<TimeFormat.duration> flow`, for example `52m flow`.
- **With Focus chosen, every Pomodoro state looks and works as today**, apart from the switch at the top.
- **A flow never touches the cycle:** `cyclePosition`, `nextKind`, `cycleDay`, `lastFinishAt` and `needsAttention` stay as they were.
- **A flow is marked by `plannedSeconds == 0`.** There's no change to the saved session format. New timer-state fields must be optional.
- **The idle stop** (600 s, `runOverIdleLimitSeconds`) applies to a flow. It never ends a flow before its start, and it plays no sound and sets no attention.
- **Under a minute:** a flow with less than 60 s of active time isn't saved (`minimumLoggedFocusSeconds`).
- **Self-check:**
  - Runs only through `scripts/self-check.sh`, against scratch data.
  - Never quits, replaces or launches `/Applications/FocusNow.app`.
  - No permission prompts and no activating other apps.
  - Idle time is faked through `fakeIdleSeconds`.

## Review Focus

1. **Owners who never touch the switch see no change.** Every existing unit test and self-check line must still pass (Task 3's full self-check run). The gaps and zoom lines are re-pointed at the cycle line under the switch, and their `(want …)` values stay the same.
2. **Changing the switch never moves the ring or the buttons.** Tested by Task 3's self-check line `flow switch`.
3. **A flow never disturbs the cycle,** including across midnight. Tested by Task 1 `flowLeavesTheCycleAlone` and `aNewDayAfterAFlowStillResetsTheCycle`.
4. **Time away never counts:** the idle stop and sleep trimming for a flow. Tested by Task 1 `tenIdleMinutesStopAFlowAtTheLastInput` and `sleepPausesAFlowAtTheLastInput`.
5. **Quitting, crashing, or the old timer state.** Quitting or a crash saves the flow as completed, and timer state saved before this change still loads. Tested by Task 1 `quittingSavesAFlow`, `relaunchAfterACrashSavesAFlow` and `snapshotSavedBeforeFlowStillDecodes`.

### Task 1: The engine runs a flow

**Files:**
- Modify: `Sources/FocusNowCore/Model.swift` (`ActiveSession`, `SessionRecord`, `EngineSnapshot`)
- Modify: `Sources/FocusNowCore/TimerEngine.swift`
- Create: `Tests/FocusNowCoreTests/TimerEngineFlowTests.swift`

**Interfaces:**
- Produces:
  - `ActiveSession.isFlow: Bool` is `kind == .focus && plannedSeconds == 0`. `SessionRecord.isFlow: Bool` is the same.
  - `EngineSnapshot.flowChosen: Bool?`, with `nil` meaning Focus.
  - On `TimerEngine`:
    - `public private(set) var flowChosen: Bool`, the switch, saved in the snapshot and restored by `recover`;
    - `public var canChooseFlow: Bool` is `status == .idle && nextKind == .focus`;
    - `public func chooseFlow(_ on: Bool)` does nothing unless `canChooseFlow`, then saves the snapshot;
    - `public var isFlowing: Bool` is `active?.isFlow == true`;
    - `public func stop()` ends a running or paused flow, saving it.

**Behaviour:**
- **`start()`,** when idle with `nextKind == .focus` and `flowChosen`, starts a flow: `ActiveSession(kind: .focus, startedAt: now, plannedSeconds: 0, lastResumedAt: now, timeUpAt: now)`. It runs `rollOverDayIfNeeded()` but doesn't set `cycleDay`. While flowing, `start()` and `skipBreak()` do nothing.
- **`stop()`, the idle stop, `prepareForQuit()` and `recover(from:)`** all end a flow through `finish` as `.completed`, without `onFinish` or `needsAttention`. The end time is:
  - `stop()` and `prepareForQuit()`: `now`;
  - the idle stop in `tick()`: `max(timeUpAt, now − idle)`;
  - `recover`: `snapshot.savedAt`.
- **`finish` for a flow:**
  - Under 60 s of active time: save nothing.
  - Otherwise save the record (`plannedSeconds: 0`, full active time).
  - Either way, skip `advanceCycle`, `cycleDay` and `lastFinishAt`.
- **`endRunOver()`** ignores flows, so the run-over paths never end a flow into a break.
- **Paths that already work for a flow:** `pause(asOf:)` (sleep trimming, never before the start) and the snapshot cadence.

    - flowing and paused: `[.resume, .stop]`.
  - **`controlRows`:** the main candidates become `[.startFocus, .startFlow, .startBreak, .pause, .resume, .stop]`. The first of `controls` found in that list is the main button, so a flow's main is `.stop`, or `.resume` when paused.

    - `TimeFormat.clock(overtimeSeconds)` with no `+` while flowing;

  - **`public var cycleLine: String`:**
    - `""` when flowing, or idle with a focus next and `flowChosen`;

  - **`public var flowLap: (completed: Int, fraction: Double)?`** is nil unless flowing. Otherwise it's `(overtimeSeconds / 3600, Double(overtimeSeconds % 3600) / 3600)`.
  - **`SRGBColor.secondLapShade() -> SRGBColor`** is the colour mixed 45 % toward black. If that has a contrast ratio under 1.4 with the original, it's mixed 45 % toward white instead.
